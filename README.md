# Catball

Мобильная игра: закидываем мячи-головы котов в кольцо. Простая механика на
один палец — тач по мячу, драг вверх набирает силу, отпускаешь — бросок.
Сделано на [Godot 4.3](https://godotengine.org/).

## Как это устроено

- `scenes/` — сцены: `Boot` → `MainMenu` → `Game` / `Shop` / `Leaderboard` / `Settings`.
- `scripts/autoload/` — синглтоны: сохранение (`SaveManager`), прогресс и
  монеты (`GameState`), громкость (`SettingsManager`), лидерборд
  (`Leaderboard` — сейчас локальный, интерфейс готов под онлайн-backend),
  магазин скинов (`ShopCatalog`), данные уровней (`LevelData`).
- `scripts/game/` — геймплей: мяч (`Ball.gd`), бегающая стрелка-прицел
  (`AimArrow.gd`), шкала силы (`PowerMeter.gd`), кольцо-сенсор
  (`RingSensor.gd`), дирижёр уровня (`GameplayController.gd`).
- `data/levels.json` — позиции и размер кольца по уровням (доли экрана).
- Вся графика v1 — процедурная отрисовка (`_draw()`), без внешних картинок:
  это осознанная заглушка на старте, см. детали в плане проекта.

## Открыть в Godot

1. Установить [Godot 4.3+](https://godotengine.org/download) (Standard, не .NET).
2. Godot → Import → выбрать `project.godot` в этой папке.
3. F5 — запустить. На десктопе мышь эмулирует тач (включено в настройках проекта).

## Как собрать APK

В этой машине нет локального Android-тулчейна (Java/SDK/Godot), поэтому сборка
APK идёт через **GitHub Actions**:

1. Запушить этот репозиторий на GitHub, в ветку `main`.
2. Открыть вкладку **Actions** → workflow «Android Build» соберёт
   debug-APK (образ `barichello/godot-ci`, экспорт без Gradle, встроенный
   debug-keystore Godot — подписи достаточно для установки на телефон, но не
   для публикации в сторе).
3. Скачать артефакт `catball-debug-apk` → файл `catball.apk`.
4. На телефоне разрешить установку из неизвестных источников и поставить APK.

Можно запустить сборку и вручную: Actions → Android Build → Run workflow.

## Экономика v1 (заглушки, легко поменять)

- За уровень: **+10 очков, +3 звезды**, фиксированно.
- 10 уровней в `data/levels.json`, кольцо каждый раз в новом месте/размере.
- Магазин (`ShopCatalog.gd`): 5 скинов мяча по цвету, цены 0/3/5/8/12 звёзд.
- Лидерборд — локальный топ-20 результатов на устройстве.
