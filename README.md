# Catbox

Мобильная игра: закидываем котов в картонную коробку. Простая механика на
один палец — тач по коту, драг в сторону броска задаёт направление и силу,
отпускаешь — бросок по прямой с остановкой (не гравитационная дуга).
Интерфейс и весь текст в игре — на английском (см. ниже), этот README — нет.
Сделано на [Godot 4.3](https://godotengine.org/).

## Как это устроено

- `scenes/` — сцены: `Boot` → `MainMenu` → `Game` / `Shop` / `Leaderboard` / `Settings`.
- `scripts/autoload/` — синглтоны: сохранение (`SaveManager`), прогресс и
  звёзды (`GameState`), громкость (`SettingsManager`), лидерборд
  (`Leaderboard` — сейчас локальный, интерфейс готов под онлайн-backend),
  магазин котов (`ShopCatalog`), данные уровней (`LevelData`).
- `scripts/game/` — геймплей: тело кота-физика (`Ball.gd`), сам рисунок кота
  (`CatVisual.gd`, дочерний узел), стрелка-прицел, привязанная к драгу
  (`AimArrow.gd`), шкала силы (`PowerMeter.gd`), коробка-сенсор
  (`RingSensor.gd`), фон-комната (`RoomBackground.gd`), дирижёр уровня
  (`GameplayController.gd`).
- `data/levels.json` — размер коробки по уровням (доля экрана); позиция
  коробки — случайная по сетке экрана, сид = номер уровня (воспроизводимо).
- Вся графика — процедурная отрисовка (`_draw()`), без внешних картинок:
  осознанная заглушка на старте, легко заменить спрайтами позже.

### Механика броска

Тач по коту → драг в любую сторону (зажато в конусе ±60° от вертикали,
чтобы бросок всегда шёл вверх к коробке). Направление драга = направление
броска, длина драга = сила (0..100%, шкала у края экрана). Калибровка:
0% — броска нет совсем, 90% — кот долетает ровно до верхнего края экрана,
между ними линейно. Долетает кот не гравитационной дугой, а прямой линией
до точки, которую даёт сила, с мягкой остановкой (`Tween`, `EASE_OUT`) —
и небольшой анимацией прыжка (приседание/вытяжение + наклон в сторону
броска). После приземления — пауза перед возвратом кота к старту, чтобы
место посадки было чётко видно.

## Открыть в Godot

1. Установить [Godot 4.3+](https://godotengine.org/download) (Standard, не .NET).
2. Godot → Import → выбрать `project.godot` в этой папке.
3. F5 — запустить. На десктопе мышь эмулирует тач (включено в настройках проекта).

## Как собрать APK

В этой машине нет локального Android-тулчейна (Java/SDK/Godot), поэтому сборка
APK идёт через **GitHub Actions**:

1. Запушить этот репозиторий на GitHub, в ветку `main`.
2. Открыть вкладку **Actions** → workflow «Android Build» соберёт
   debug-APK (образ `barichello/godot-ci`, экспорт без Gradle, встроенный
   debug-keystore Godot — подписи достаточно для установки на телефон, но не
   для публикации в сторе).
3. Скачать артефакт `catbox-debug-apk` → файл `catbox.apk`.
4. На телефоне разрешить установку из неизвестных источников и поставить APK.

Можно запустить сборку и вручную: Actions → Android Build → Run workflow.

Android package id — `com.catbox.game` (раньше был `com.catball.game`:
если на телефоне стоял старый `catball.apk`, он не обновится поверх —
это отдельное приложение, старое стоит удалить вручную).

## Экономика v1 (заглушки, легко поменять)

- За уровень: **+10 очков, +3 звезды**, фиксированно.
- 10 уровней в `data/levels.json`, коробка каждый раз в новом месте/размере.
- Магазин (`ShopCatalog.gd`): 5 котов по цвету, цены 0/3/5/8/12 звёзд.
- Лидерборд — локальный топ-20 результатов на устройстве.
